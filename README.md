# Mirror Hacker

A Chrome extension that mirrors your text in real-time to protect it from shoulder surfers while keeping the actual input normal.

## Features
- Real-time text mirroring
- Toggle on/off via popup
- Works on all websites
- Lightweight and secure

## Installation
1. Clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable "Developer mode."
4. Click "Load unpacked" and select the `mirror-hacker-new` folder.

## Usage
- Click the extension icon to toggle mirroring.
- Type in any text field—your input will appear mirrored (e.g., "Hello" becomes "olleH").
- Submit forms as usual; the real text is sent.
